Cómo funciona

  1. Sube los archivos de este proyecto a un repositorio de GitHub y activa GitHub Pages.
  2. Conecta esta página con el usuario, repositorio, rama y un token de permiso limitado.
  3. Agrega, edita, oculta o elimina productos y pulsa Publicar cambios en GitHub.
  4. GitHub guarda una versión del archivo. La web pública refleja el cambio después de que GitHub Pages se actualice.

Si todavía no tienes repositorio, utiliza «Editar menú local», descarga el JSON actualizado y reemplaza data/menu.json manualmente.
